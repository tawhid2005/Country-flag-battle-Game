# Country Flag Battle Royale (24/7 YouTube Vertical Live 9:16)

Autonomous 24/7 Country Flag Battle Royale simulator engineered specifically for YouTube Live (9:16 vertical stream) and TikTok Live broadcasts.

## Features
- **Matter.js 2D Physics Engine**: High-energy circular rotating arena with kinetic flippers, super-bouncy neon pinball bumpers, and dynamic hazard gates.
- **Dual-Tier Flag Engine**: Procedural vector flag renderer + official FlagCDN high-res textures.
- **3D Glossy Championship Marbles**: Specular lighting glints, metallic championship rims, and clean visuals.
- **Royal Victory Podium**: Golden sunburst rays, laurel wreath crest, 3D animated crown, and 7-second high-tech circular countdown.
- **1v1 Final Showdown Banner**: Dramatic esports slam entrance, flame/cyan split styling, and cinematic sub-bass audio stinger.
- **Procedural Web Audio Synth**: 100% Content-ID safe procedural audio synthesis (bounce pops, bumper hits, shield pickups, bomb detonations, heartbeat loop, victory chimes).
- **Streamer Control Drawer**: Press `H` or click ⚙️ to adjust gravity, rotation speed, batch size, or test screens.

## Quick Start
Open `index.html` in any modern web browser or add as a Browser Source in OBS Studio (1080x1920 or 9:16 vertical canvas).
