## 🎥 OBS Setup & 24/7 Broadcasting Guide

1. **Set 9:16 Canvas in OBS**:
   - Go to `Settings > Video`.
   - Set **Base Canvas Resolution** to `1080x1920`.
   - Set **Output (Scaled) Resolution** to `1080x1920`.
   - Set FPS to `60 FPS`.
2. **Add Browser Source**:
   - In Sources, click `+ > Browser`.
   - **URL**: `https://countryflagbattlegame.vercel.app/`
   - **Width**: `1080`
   - **Height**: `1920`
   - Check `Control audio via OBS`.
3. **Start Stream**:
   - Click `Start Streaming` to YouTube Live or TikTok Live Studio.
   - The game continuously loops rounds, counts down intermissions, and celebrates champions automatically 24/7.
